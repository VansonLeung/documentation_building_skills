# 音訊、波形與圖解

## 選擇圖解

| 要說明的問題 | 適合的呈現 |
|---|---|
| 處理先後與分支 | SVG／Mermaid／原生 HTML 流程圖 |
| 同一樣本原音與處理版 | 對齊波形、短音訊與文字比較 |
| 先找語音再轉錄 | 帶時間軸的聲音／門檻示意／ASR 片段 |
| 對話交錯 | A/B 對話時間或訊息順序圖 |
| 計數或分布 | 共用資料生成的 bar／table，清楚標單位及分母 |
| 相依與規劃 | 甘特圖＋里程碑＋工日表 |

區分軸：真實音訊的時間、對話的訊息順序，以及教學示意的步驟，不能看起來都是實測時間。

## 音訊例子

只有聲音本身能幫助理解的頁面才加播放器。優先選短而有代表性的已核准樣本；不要為裝飾生成新聲音。真實音訊、原始／處理版和合成樣本分別標記。

波形從 PCM 或已解碼音訊計算，記錄 sample rate、聲道、裁切起止及來源雜湊。原音／處理版使用相同時間範圍；若各自 normalize 振幅，明確說明，不能憑外觀宣稱音量改善。

合成時間軸可插入靜音或訊號間隙作演示，但必須說明構造方式。沒有實際跑 VAD／ASR，框線、門檻、偵測段及文字就標為示意；不能只因波形來自真音訊便稱為模型結果。

## 播放與可攜

- 無 autoplay；一次只播放一段；換頁／換語言時暫停。
- 控制項可用鍵盤，顯示樣本文字、語言、來源及狀態。
- 本機 HTML 驗證 seeking、duration 及媒體載入；若宣稱離線，停用網路測試。
- PDF 顯示完整靜態波形、文字比較及相對聆聽頁連結；附上純文字檔名作備援。
- 不以簡單字串遮蔽宣稱真實聲音已匿名。優先用已核准合成例子；任何處理仍須人工檢查。

## 圖表一致性

同一維度使用同一色碼，例如 channel colors；其他維度使用獨立且可辨認的 palette。標示數字、文字、pattern 或直接標籤，不僅靠顏色。資料不足／缺錄使用缺失狀態，不畫成零。

時間箱資料使用階梯／直線面積或 bars；平滑曲線可能暗示不存在的中間值，需要有理由才使用。堆疊數值必須可相加；比例圖需交代分母、缺失及分類重疊。
