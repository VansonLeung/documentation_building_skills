# 雙語內容與術語

共用資料／章節 ID，分開語言文字。優先沿用既有資料模型，不為小幅修訂另建翻譯系統。

## 建議約定

- `en`、`zh-Hant` 是這次專案的語言代碼；其他專案可以設定其他代碼。
- chapter_id、figure_id、table_id、source_ref 在雙語間相同；日期、數字、計量單位、分母及資料狀態一致。
- 術語表記錄 canonical_key、英文、繁中、定義和避免用語。不要把 dialogue、transmission、clip 或 event 當成同義字。
- 原始提示詞／schema 維持原文及順序；翻譯置於旁邊作說明，不覆蓋原文。
- 顯示數字可依語言格式化，但底層數值相同；不要靠比對格式化字串判斷資料等價。

## 翻譯與修訂

先改共用資料和結構，再改兩套文字，再逐圖／逐表核對。更新一種語言時，標記另一版待同步，交付前清除真正未完成內容，不把只完成一種語言寫成雙語完成。

正文使用讀者熟悉的詞彙及短句。程式識別、API 名稱、模型名及參數保持精確。香港繁中用語與官方術語按專案約定；不硬套某一專案的簡稱。

雙語切換應保留章節／投影片位置；音訊切換時暫停舊播放器。語言切換後要重查表格寬度、中文行高、長標題及 PDF 分頁。

## 驗證

`check_documentation.py` 的 `bilingual` 可比對指定的 anchor IDs；`required_text` 可檢查封面或重要標示。這只驗證結構及字串存在，不驗證翻譯正確或數字語意。資料層仍需對照共用來源，兩版也需人工閱讀。
