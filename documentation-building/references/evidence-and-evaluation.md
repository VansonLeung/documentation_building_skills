# 證據、評測與說法

## 來源紀錄

可採用下列欄位；依任務精簡：

```text
source_id, locator, source_version, sha256, collected_at,
population, unit, transformation, review_status, shared_copy
```

locator 可指向程式、資料庫唯讀快照、API 輸出、覆核 JSON 或設定。來源清單應可重找證據，但共享版可用相對位置及遮蔽索引；不暴露私人服務位址或機器絕對路徑。

原始資料、衍生資料和文案分開。每個關鍵結論連到足以支持它的來源。保留對原始提示與結果的雜湊，不因對外改顯示名稱而改寫原始記錄。

## 評測摘要至少交代

| 欄位 | 應說明 |
|---|---|
| Task | 比較的是識別、含義支持、語言控制還是延遲 |
| Population | 幾段音訊、幾個文字、幾個生成；是否重複同一句 |
| Condition | 模型版本、量化、原音／處理版、提示、抽樣與硬件 |
| Reference | 由誰／如何覆核，哪些部分尚未核對 |
| Metric | 分子、分母、排除、缺失及統計方法 |
| Split | 開發、調整、保留測試；有沒有看過評價再調參 |
| Scope | 結果能支持的決定及不能推廣的範圍 |

結構／schema 通過、人工覺得含義正確、語音清晰、字詞正確是不同指標。多次生成不等於相同數量的獨立句子。不同母體的計數不可直接相加。

## 狀態標示

- **Measured**：可連到實際執行、條件及時間紀錄。
- **Reviewed**：明確的人工判斷及覆核範圍。
- **Observed**：定性開發觀察，未形成完整評測分母。
- **Illustrative**：教學或合成示例，沒有當成實際偵測結果。
- **Estimated / Proposed**：推算、未來設計或目標配置。
- **Unreviewed / Unavailable**：尚未覆核或沒有資料；不可自動填零。

模型不能偵測的現象，不應寫成「沒有偵測到所以不存在」。對數值的疑問優先查上游來源、單位和範圍，不用文字修飾掩蓋。

## 文件修訂的邊界

既有評測可整理和重算，但標明是否改了母體或公式。未獲准時不為補文件再送模型請求、上傳音訊、重做標籤或寫入生產資料。文中所稱「改善」須有相應比較；沒有證據的整體勝率或完整性能排名不補造。
