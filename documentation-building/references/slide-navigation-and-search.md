# 簡報閱讀、搜尋與跳頁

長篇培訓或需要會後查閱的簡報，可提供演講與閱讀模式；短會議 deck 按需求選用，不必為每份文件加入整套控制。

## 入口與版面

若同時交付一般使用者、技術人員及參考手冊，可做一個本機文件入口，列明每份材料用途、版本、語言和下載格式。不要把只有內部用途的下載連結放進外部首頁。

可重用版型包括：

- 截圖為主、下方一句操作提示：介紹畫面及主要用途。
- 截圖＋旁側三個 callouts：「看到甚麼 → 先檢查甚麼 → 下一步」。適合錯誤排查。
- 短 steps 或流程圖：教順序，不用大幅全頁截圖代替所有解說。
- 獨立 appendix：密集設定與詳盡技術內容放後段，講者可按問題跳入。

字體、留白及版型可參考 LD 範例，但色彩、brand、作者、尺寸應由各專案設定。小字截圖可加裁切放大或連原圖；提高輸出解析度不能增加來源圖像本來沒有的細節。

## 兩種模式

演講模式以 stable slide_id 定位；閱讀模式把投影片順序展開。切換時保留正在看的投影片，並可在每張旁加入「播放此頁」控制。離開閱讀模式時返回該頁，而不是一律跳第一張。

閱讀模式應可正常捲動，停用 Reveal 的頁面攔截鍵，避免滑鼠／鍵盤被隱藏投影片遮擋。演講模式恢復方向鍵及焦點。fixed 16:9 畫布在手機可能太小或橫向溢出，需另外決定縮放／閱讀替代，不因桌面可用而宣稱 mobile 已優化。

語言切換使用相同 slide_id 對應；重排後不只靠頁碼映射。有音訊或 fragments 時，明確定義切換後暫停／顯示狀態，避免背景繼續播放。

## 搜尋契約

預設索引標題及可見教學文字；講者備註為可選範圍。可採用以下資料模型：

```text
slide_id, display_order, title, visible_text,
approved_notes, preview, language
```

只在使用者選用且備註已獲准分享時，才將 approved_notes 納入索引。對外檔必須從 HTML、內嵌資料、source maps 和 Office notes 中移除私人備註；只關閉索引或用 CSS 隱藏不能達到不交付的效果。

搜尋標題可優先排序，再比正文；可選 prefix／輕微拼字錯誤容忍。圖片中的字未做 OCR 就說明未納入，不把 alt text 當成完整截圖內容。空白查詢應明確定義為列全部或顯示提示。

英文 word-based matching 不能直接當成完整中文搜尋。繁中至少測試連續字串內的中間詞，例如「如何辨識對話交錯」應可找到「對話」；可使用經測試的 substring、斷詞或 n-gram。中英文混合、全半形、數字／callsign 和無結果情況都需檢查。

## 互動及輸出

- `/`、Ctrl/Cmd+K 可用作搜尋快捷鍵；避免與 Reveal blackout 等功能衝突。
- 在輸入框／對話框內，方向鍵、空白鍵和 Escape 不應觸發投影片操作；關閉後恢復合理焦點。
- Enter 跳轉結果、Escape 關閉；結果數及無結果提示可被輔助技術讀取。
- 演講模式搜尋結果跳指定頁；閱讀模式捲到指定頁。測試向前／向後及從中途返回。
- 需離線時測 HTTP 及 file://；優先用可直接載入的本機腳本或既有 offline bundle，不讓搜尋依賴登入或外部服務。
- 搜尋 UI、閱讀控制及開啟的搜尋對話框，不應出現在 PPTX／PDF 畫面；PDF 可保留可選取正文，圖片式 PPTX 限制見 [office-exports.md](office-exports.md)。

技能已附獨立的 `assets/presentation/search.js`／`controls.js`，按 LD 行為抽離並調整中文搜尋與備註範圍；使用 [standalone-toolkit.md](standalone-toolkit.md) 的範本建立指令。測試用本 repository 的獨立樣本，不替換兩個既有專案的 controls。抽離來源及 hashes 見根目錄 provenance.json。
